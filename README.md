# Landing Page Studio

Landing page per lo Studio Tamburrini, amministrazione e gestione condomini a Napoli.

## Sviluppo

Sono necessari Node.js e Bun.

```sh
bun install --frozen-lockfile
bun run dev
```

## Build

```sh
bun run build
bun run preview
```

## Pubblicazione

Il branch `main` viene pubblicato automaticamente su GitHub Pages tramite GitHub Actions.
